# Module irurueta-android-recycler-tab-layout

A tab layout implemented on top of a RecyclerView that draws and recycles tab views, so that very
large numbers of tabs can be displayed without the memory cost of Android's TabLayout. It looks
like a TabLayout (selection indicator and animations) but tabs are populated through a regular
RecyclerView adapter.

# Package com.irurueta.android.recyclertablayout

Contains `RecyclerTabLayout`, the view that shows the tabs and the animated selection indicator,
which is populated and recycled like any other RecyclerView.
